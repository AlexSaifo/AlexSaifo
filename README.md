## 👋 About me

I'm **Ali Saifo**, a Software and AI Engineer based in Damascus, Syria. I build secure, accessible, high-performance products across modern frontend systems, full-stack platforms, and applied AI/NLP.

- 🏥 Frontend Developer at **Ntigra AI Applications**, building bilingual healthcare workflows with React and TypeScript
- 🧠 Specialized in **Artificial Intelligence, NLP, and Data Science** at Damascus University
- 🧩 Interested in design systems, scalable architecture, automated testing, and developer experience
